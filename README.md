 QuizMobile - Aplicativo de Quiz Android

Projeto desenvolvido para a **Prova 1 da disciplina de Desenvolvimento Mobile** na **Faculdade Senac-DF**.

---
 Sobre o Projeto

O **QuizMobile** é uma aplicação nativa para Android desenvolvida em Java. O objetivo principal do aplicativo é aplicar um questionário interativo de múltipla escolha aos usuários, realizando a validação dos dados de entrada, o processamento da pontuação e a transição entre telas com exibição dos resultados.

---
 Funcionalidades

- **Validação de Entrada:** Impede o envio do formulário sem o preenchimento prévio do nome do usuário ou seleção das perguntas.
- **Fluxo Interativo:** Navegação fluida entre a tela principal do questionário (`MainActivity`) e a tela de resultado (`ResultadoActivity`).
- **Cálculo de Nota Automatizado:** Processa os acertos selecionados e gera a nota final e o número de acertos em tempo real.
- **Feedback ao Usuário:** Notificações instantâneas via `Toast` para campos não preenchidos.

---
 Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE:** Android Studio
- **Interface:** XML Layouts (`RelativeLayout`, `RadioGroup`, `RadioButton`, `EditText`, `Button`)
- **SDK Alvo:** Android 8.0+ (API level 26+)
